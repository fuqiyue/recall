# GitHub 仓库配置指南

## About 描述（160 字符以内）

```
AI-powered design decision tracker. Records WHY decisions were made, not WHAT code looked like.
```

或中文版本：

```
AI 驱动的设计决策追溯系统，记录"为什么"而非"是什么"，让代码修改有据可查。
```

## 手动设置步骤

1. 访问 https://github.com/fuqiyue/recall/settings
2. 在 "About" 部分：
   - 输入 Description
   - 添加 Topics（点击齿轮图标）
3. 保存更改

## 使用 GitHub CLI 设置（如果已安装 gh）

```bash
# 更新仓库描述
gh repo edit fuqiyue/recall --description "AI-powered design decision tracker. Records WHY decisions were made, not WHAT code looked like."

# 添加 Topics（需要使用 API）
gh api repos/fuqiyue/recall/topics \
  -X PUT \
  -f names[]=ai-assisted-development \
  -f names[]=design-decisions \
  -f names[]=decision-tracking \
  -f names[]=git-integration \
  -f names[]=claude-ai \
  -f names[]=version-control \
  -f names[]=documentation \
  -f names[]=developer-tools \
  -f names[]=architecture-documentation \
  -f names[]=software-architecture \
  -f names[]=development-workflow \
  -f names[]=knowledge-management \
  -f names[]=code-reasoning \
  -f names[]=design-rationale \
  -H "Accept: application/vnd.github.mercy-preview+json"
```
