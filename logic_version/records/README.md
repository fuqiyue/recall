# 历史决策记录目录

本目录保存已完成的重要决策记录。

## 逻辑回档原则

**记录内容（轻量）：**
- 为什么做这个决策
- 考虑过哪些方案（A/B/C）
- 为什么选择当前方案
- 影响范围和消费者
- 验证和回滚方式

**不记录（避免上下文膨胀）：**
- 完整代码快照
- 逐行代码 diff
- 原始对话记录
- 详细实现细节

---

## 记录命名规则

```
logic_version-YYYYMMDD-NNN-<scope>.md
```

示例：
- `logic_version-20260807-001-auth.md` - 用户认证决策
- `logic_version-20260807-002-api-refactor.md` - API 重构决策

---

## 首次创建指南

当完成第一个高风险变更后，创建记录文件，包含：

1. **元数据**：CHG-ID、日期、状态、决策确认
2. **为什么这么设计**：问题、需求、约束
3. **方案对比**：A/B/C 方案及取舍
4. **影响范围**：消费者、API、数据
5. **验证方式**：测试、检查点
6. **回滚方式**：恢复路径

参考：`references/logic-version-template.md`
